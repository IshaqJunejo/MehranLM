# Pipeline

## Overview

This directory contains pipeline scripts for processing the corpus, including cleaning and deduplication, exploratory data analysis (EDA), Quality Assurance (QA), tokenization and models.
Each subdirectory contains specific scripts focused on a particular aspect of corpus processing.

## Directory Structure


### **`cleaning/`**
- **`__init__.py`**, makes the python script in the directory usable outside the directory, where this directory as can be used as a module.
- **`corpus_cleaning.py`**, cleans the corpus by removing unwanted symbols, characters, and diacritics; it also performs deduplication on each file.
- **`parsing_sindhi_legal.py`**, parses the `Sindhi_Legal_Dataset.csv` file and writes the questions and answers on a text file.

### **`EDA/`**
- **`__init__.py`**, makes the python scritps in the directory usable outside the directory, where this directory can be used as a module.
- **`char_entropy.py`**, shows the **character-level entropy** for each file in the corpus, **Raw** and **Cleaned** both.
- **`char_frequency.py`**, calculates the frequency of each character in our entire corpus and writes that information to a file.
- **`char_frequency.txt`**, contains each character, its name, and how many times it appears in our corpus; generated by `char_frequency.py`.
- **`sentence_length.py`**, splits each file in our corpus on punctuations and newlines, tokenizes the sentences, and shows the stats for **Total Tokens**, **Mean Sentence Length**, **Token Lengths in Percentiles**, for each file in the corpus.
- **`unique_char.py`**, a script to identify unique characters in the corpus.
- **`unique_chars.txt`**, contains all the unique characters in our corpus; generated by `unique_char.py`.

### **`model/`**
- **`char_LSTM_checkpoints/`**, stores the weights of the char-based LSTM at epoch checkpoints. Currently only stores for **Epoch no 25** as the training has been finished.
- **`perplexity_scores/`**, stores the perplexity scores of each corpus file in a JSON file. Also stores the **mean**, **median**, and **standard deviation** of the scores.
- **`__init__.py`**, makes the python scripts in the directory usable outside the directory, where it can be used as a module.
- **`char_LSTM.py`**, for training a Char-based single-layered LSTM on a hand-picked subcorpus (almost 300 KB of text).
- **`perplexity_analysis.py`**, for calculating the perplexity of each corpus file using the char-based LSTM.
- **`testing_char_LSTM.py`**, for testing the Char-based LSTM on multiple temperatures and user-input seed texts.
- **`text_generated_by_char_LSTM.txt`**, one of the output of `testing_char_LSTM.py` being piped to a txt file. 
- **`vocab.json`**, stores the `char_to_idx` and `idx_to_char` mappings; generated by `char_LSTM.py`.

### **`QA/`**
- **`analyze_long_sentence.py`**, reads the `sindhi_wiki_artciles_cleaned.txt` file, splits into setences, tokens the sentences, and randomly samples 25 of the sentences with token-length of 75+, and writes them to a file, so the semantics of abnormally long sentence be manually analyzed.
- **`sentence_longer_than_75_tokens.txt`**, stores 25 randomly sampled sentences of abnormal token-length; generated by `analyze_long_sentences.py`.

### **`tokenization/`**
- **`__init__.py`**, makes the python scritps in the directory usable outside the directory, where it can be used as a module.
- **`tokenizer.json`**, used as the *token dictionary* of our tokenizer; generated by `tokenizer.py`.
- **`tokenizer.py`**, used for training the tokenizer, and also for **encoding** and **decoding** *text to tokens* and *tokens to text*; uses the `Tokenizers` library.

### **`tokenizer_benchmarking/`**
- **`llama_tokenizer_files/`**, stores the tokenizer-related files for the tokenizer of **meta-llama/Llama-3.1-8B**.
- **`mehranLM_tokenizer_files_with_diacritics/`**, stores the tokenizer-related file for a slightly modified version of **MehranLM-Tokenizer**, as this version does not Normalize the Diacritics.
- **`results/`**, stores the JSON files for the result of tokenizer benchmarking on each testing dataset.
- **`__init__.py`**, makes the python scripts in the directory usable outside the directory, where it can be used as a module.
- **`benchmark_tokenizers.py`**, performs a benchmark of 10 different tokenizers on 3 different testing datasets.
- **`download_llama_tokenizer.py`**, downloads the tokenizer-related files for the tokenizer of **meta-llama/Llama-3.1-8B** from HuggingFace and stores in the `llama_tokenizer_files/` directory.
- **`parse_sindhi_misspelled_data.py`**, loads the `Sindhi Misspelled Setences Dataset` from HuggingFace, read the initial *100K* sentences from both **Misspelled** and **Corrected** category and write them to 2 different `.txt` files.
- **`parse_sindhi_sentiment_data.py`**, parses the `sindhi_sentiment_cleaned.csv` file and writes the sentences to a `.txt` file.
